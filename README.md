# Danesh Patel — AI & Data Engineering Portfolio

A recruiter-focused portfolio website for Danesh Patel.

## Run locally
Open `index.html` in a browser.

## Before publishing
1. Replace the placeholder LinkedIn URL with your real profile.
2. Replace the placeholder GitHub URL with your real GitHub profile.
3. Add public project repository links when available.
4. Review the Eisai section against your NDA/confidentiality requirements.

## Deploy
This static site can be deployed on GitHub Pages, Netlify, Vercel, or another static hosting service.

## Profile photo
`profile.jpg` is the profile image supplied for the portfolio hero section.
